Core Mathematical Formulations THEORETICAL FRAMEWORK
1. Weibull 2-Parameter Cumulative Failure Hazard & RUL Decay
$$h(t) = \frac{\beta}{\eta} \left(\frac{t}{\eta}\right)^{\beta-1}, \qquad h_{\text{decay}}(t) = 1 - \exp(a \cdot d - b \cdot t^c)$$

2. NASA PHM'08 Asymmetric Prognostics Scoring Function
$$S = \sum_{i=1}^N \begin{cases} \exp\left(-\frac{d_i}{10}\right) - 1 & \text{if } d_i < 0 \text{ (early RUL prediction)} \\[6pt] \exp\left(\frac{d_i}{13}\right) - 1 & \text{if } d_i \ge 0 \text{ (late RUL prediction)} \end{cases}$$
Heavily penalizes late RUL predictions ($d_i \ge 0$) to prevent catastrophic engine in-flight failures while favoring conservative early warnings.
3. Dynamic Environment-Corrected Thermal Limit (Ideal Gas Correction)
$$T_{\text{dynamic}} = T_{\text{nominal}} + \alpha \cdot \left( \frac{T_{\text{ambient}} - 15^\circ\text{C}}{1.5} \right)$$

4. Isolation Forest Normalized Anomaly Scoring
